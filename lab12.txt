```WARIANT 1:```
git clone https://git.pg.edu.pl/p18685/so-scheduler.git
cd so-scheduler

Stwórz plik scheduler/stcf.py

W pliku main.py (w katalogu so-scheduler-main/):
 import scheduler.stcf as stcf
oraz w słowniku schedulers:
 'stcf': stcf.schedule

Stwórz plik jobs.txt (w katalogu so-scheduler-main/) z treścią:
job_name,priority,burst,start_time,deadline
A,1,6,0,15
B,2,2,1,15
C,1,8,2,15
D,3,3,3,15

 Uruchomienie algorytmu STCF:
python3 main.py jobs.txt stcf
